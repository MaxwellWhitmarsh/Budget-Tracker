# Budget-Tracker for CS361
# Milestone #1 in progress

# User Stories

**User Story 1: Add Expense**
**User Story:**  As the user, I want to add an expense with an amount, category and description so that I
have a record of what I spent.
**acceptance criterion:** Given I am on the Add Expense page, when I fill in the form and click save, then I see a Saved message.

**User Story 2: View Expense**
**User Story:**  As a user, I want to be able to view all my expenses so that I can see how 
much I spent. 
**acceptance criterion:** Given I have added expenses, when I open View Expenses, then I see my expenses and the total.

**User Story 3: Delete Expense**
**User Story:**  As a user, I want to be able to delete an expense if I want to remove an 
expense if I ever make a mistake. 
**acceptance criterion:** Given I have expenses, when I delete it, then it is gone and I can undo it.

# Inclusivity Heuristics

**IH#1:** Explain (To Users) why this feature is useful.
**Explanation:** The Add Expense page says to the user "Record each expense to see where your money goes.".  

**IH#2:** Explain (To Users) what happens if they use a feature.
**Explanation:** whenever the user deletes an expense from their list it will prompt a message to tell them that the 
expense will be removed from the total but the change can be undo. 

**IH#3:** let users see more or less info.
**Explanation:** On the View Expense page, the list has a show and hide feature where the user can see the list 
of expenses with the date, category, cost, and description of each expense.

**IH#4:** Let users keep things in the same place.
**Explanation:** Have a nav bar to appear on each page so that the users will know how to go where Home, Add 
Expense, or View Expense.

**IH#5:** Let users undo mistakes.
**Explanation:** Added an undo feature for the delete option so that if the user made a mistake on deleting an 
expense from their list then they have the option to undo that change.

**IH#6:** Explain (to Users) on how to navigate this feature.
**Explanation:** Added instructions to the Add Expense page with a short list of instructions called hint to help 
give the users a guide on how to use the Add Expense feature.

**IH#7:** Let users have more than one option to go to a page.
**Explanation:** Users can either pick their own category or they can type it on their own whenever they are 
calculating the total cost of their expenses. 

**IH#8:** Let users try things safely.
**Explanation:** Whenever the user uses the delete feature, it will prompt the exact expense they chose to 
delete and ask the user if they are sure if they want to delete this expense.
